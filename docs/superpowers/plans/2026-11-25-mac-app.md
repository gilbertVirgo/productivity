# Stint Mac App Implementation Plan (plan 3 of 8)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working macOS app called **Stint**: menu bar timer plus a window (Today, Projects, Rewards). It runs planned-length sessions, watches the frontmost app and browser tab, nudges when you drift, makes ending early slow, and keeps a points ledger with treats. All data is stored locally. Sync comes in plan 4.

**Architecture:**
- Session rules live in `Core` as a new pure `SessionEngine`, unit-tested like plan 1.
- The Mac app (`Mac/`) is a thin SwiftUI + SwiftData shell:
  - `AppState` owns the running engine and a 1 s timer.
  - `ActivityMonitor` feeds it the frontmost app, browser host, idle and sleep.
  - Views read `AppState` and SwiftData.
- The Xcode project is generated by XcodeGen from `project.yml` and is not committed.

**Tech Stack:** Swift 6, SwiftUI (`MenuBarExtra`, `Window`, `NavigationSplitView`), SwiftData, AppKit (`NSWorkspace`, `NSAppleScript`, `NSPanel`), UserNotifications, XcodeGen 2.48, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-24-freelance-focus-app-design.md` (§3, §5, §6.2–6.8, §7). The artboard (https://claude.ai/artifact/7jLEB3FF9u9ocTp9XV8YCZ) shows the intended look: system font, greys, accent `#0064D2`, project colours teal `#0F7B6C`, amber `#B7671F`, purple `#6E56CF`, blue `#2F6FB5`, rose `#B5476A`.

## Global Constraints

- App name **Stint**; bundle ID `dev.stint.mac`; macOS 14+.
- Swift 6 language mode. `Core` stays Foundation-only and pure.
- **Not sandboxed** (Apple Events to Safari/Chrome). Hardened runtime with entitlement `com.apple.security.automation.apple-events`. Ad-hoc signing (`CODE_SIGN_IDENTITY = "-"`); no Apple Developer account needed.
- Off-task grace 15 s; idle after 5 min with no input; break allowance 60 min/day by default; end-early cooldown 60 s with a required reason; session lengths 25 / 50 / 90 min.
- Points come only from `Core` (`sessionPoints`, `breakOverAllowance`, `canRedeem`). Goal points (+20/+100) are **not** awarded in this plan; the server period-close job (plan 2) owns them. The UI shows goal status only.
- Time totals come only from `Core` (`sessionTotals`, whole-second rule).
- Persisted field names mirror spec §5 so plan 4 can sync them.
- SwiftPM inside this agent environment: `swift test --disable-sandbox`. If `xcodebuild` fails with `other(28)` / sandbox errors, re-run that Bash command with the sandbox disabled.
- Work directly on `main`. Commit trailer: `Co-Authored-By: <model you run as> <noreply@anthropic.com>`.

## Decisions taken in this plan (rulings against the spec)

- No "start a break?" prompt after a completed session. Spec 6.5 says breaks exist only inside a session, so the completion notification just reports points.
- "System Settings is on-task while our permission prompt shows" is dropped for now. macOS's Automation prompt is a system dialog, so we can't tell when the user opens System Settings for it. The `setExtraAllowed` API stays for later use.
- History view and Friends section are not in this plan (spec lists them; plan 8 adds Friends; History waits until there is synced data to show).
- If Stint quits mid-session, the open session is closed on next launch as ended early, with reason "Stint quit during session" and its last saved time. This prevents data loss.

```swift
    public static func normalizeDomain(_ raw: String) -> String {
        var s = raw.trimmingCharacters(in: .whitespacesAndNewlines).lowercased()
        if let r = s.range(of: "://") { s = String(s[r.upperBound...]) }
        if let i = s.firstIndex(where: { "/?#:".contains($0) }) { s = String(s[..<i]) }

        while s.hasPrefix(".") { s.removeFirst() }
        while s.hasSuffix(".") { s.removeLast() }
        if s.hasPrefix("www.") { s.removeFirst(4) }
        return s
    }
```

```swift
import Foundation

/// What the progress views need from one finished session.
public struct SessionSummary: Sendable, Equatable {
    public var projectID: UUID
    public var startedAt: Date
    public var focusedSec: Int
    public var breakSec: Int

    public init(projectID: UUID, startedAt: Date, focusedSec: Int, breakSec: Int) {
        self.projectID = projectID
        self.startedAt = startedAt
        self.focusedSec = focusedSec
        self.breakSec = breakSec
    }
}

/// A session counts toward the period it started in (spec 6.1).
func startedIn(_ s: SessionSummary, _ interval: DateInterval) -> Bool {
    s.startedAt >= interval.start && s.startedAt < interval.end
}

public func focusedSec(_ sessions: [SessionSummary], projectID: UUID, in interval: DateInterval) -> Int {
    sessions.filter { $0.projectID == projectID && startedIn($0, interval) }.reduce(0) { $0 + $1.focusedSec }
}

public func breakSec(_ sessions: [SessionSummary], in interval: DateInterval) -> Int {
    sessions.filter { startedIn($0, interval) }.reduce(0) { $0 + $1.breakSec }
}
```

### Task 2: Core: SessionEngine

**Files:**
- Create: `Shared/Sources/Core/SessionEngine.swift`
- Test: `Shared/Tests/CoreTests/SessionEngineTests.swift`

**Interfaces:**
- Consumes: `Allowlist`, `AllowEntry`, `Browsers`, `OffTaskTracker` (its `observe`, `tick`, `allow`, `setSuspended`, `setExtraAllowed`, `isOffTask`, `allowlist`), `SessionEvent`, `sessionTotals`, `isComplete`, `breakOverAllowance`, `sessionPoints`, `PointLine`.
- Produces:
  - `struct FrontApp: Equatable, Sendable { bundleID: String; host: String? }`
  - `struct SessionResult: Sendable { totals: SessionTotals; completed: Bool; points: [PointLine]; events: [SessionEvent]; allowAdded: [AllowEntry] }`
  - `struct SessionEngine: Sendable`, with:
    - `init(plannedMin: Int, startedAt: Date, allowlist: Allowlist)`
    - `enum Signal: Equatable { case offTaskStarted(bundleID: String, host: String?), offTaskEnded, reachedPlannedLength }`
    - read-only: `plannedMin`, `startedAt`, `events`, `onBreak`, `idle`, `asleep`, `front: FrontApp?`, `lastOnTaskBundleID: String?`, `allowAdded`, `isOffTask`, `allowlist`
    - `mutating observe(bundleID:host:at:) -> [Signal]`
    - `mutating tick(at:) -> [Signal]`
    - `mutating setBreak(_:at:)`, `setIdle(_:at:)`, `setAsleep(_:at:)`, each `-> [Signal]`
    - `mutating allowCurrent(at:) -> (entry: AllowEntry, signals: [Signal])?`: allows the app in front **now**. That is the tab's domain when a supported browser's host is known; otherwise the app's bundle ID.
    - `mutating setExtraAllowed(_:at:) -> [Signal]`
    - `func totals(at:) -> SessionTotals`
    - `func remainingSec(at:) -> Int`
    - `mutating finish(at:early:breakUsedEarlierTodaySec:allowanceSec:) -> SessionResult`

Rules:
- The tracker is suspended while `onBreak || idle || asleep`. The engine owns that combined flag, so callers can't get it wrong.
- Every tracker output is recorded as a `SessionEvent` (`offtask_start` at its stamped time, `offtask_end`). Break, idle and sleep changes record their own events, and only on a real change.
- `reachedPlannedLength` fires once, on the first tick where `isComplete`.
- `finish` closes open states. It appends `offtask_end` if off-task, `break_end`, `idle_end`, and `wake` at `now`, then computes totals, `completed = !early && isComplete`, break overflow, and points.

```swift
import Foundation

public struct FrontApp: Equatable, Sendable {
    public var bundleID: String
    public var host: String?
    public init(bundleID: String, host: String?) { self.bundleID = bundleID; self.host = host }
}

public struct SessionResult: Sendable {
    public var totals: SessionTotals
    public var completed: Bool
    public var points: [PointLine]
    public var events: [SessionEvent]
    public var allowAdded: [AllowEntry]
}

/// Rules for one running session (spec 6.3–6.7). Pure: the caller feeds observations and clock ticks.
public struct SessionEngine: Sendable {
    public enum Signal: Equatable, Sendable {
        case offTaskStarted(bundleID: String, host: String?)
        case offTaskEnded
        case reachedPlannedLength
    }

    public let plannedMin: Int
    public let startedAt: Date
    public private(set) var events: [SessionEvent] = []
    public private(set) var onBreak = false
    public private(set) var idle = false
    public private(set) var asleep = false
    public private(set) var front: FrontApp?
    public private(set) var lastOnTaskBundleID: String?
    public private(set) var allowAdded: [AllowEntry] = []
    var tracker: OffTaskTracker
    var completionSignalled = false

    public init(plannedMin: Int, startedAt: Date, allowlist: Allowlist) {
        self.plannedMin = plannedMin
        self.startedAt = startedAt
        self.tracker = OffTaskTracker(allowlist: allowlist)
    }

    public var isOffTask: Bool { tracker.isOffTask }
    public var allowlist: Allowlist { tracker.allowlist }

    public mutating func observe(bundleID: String, host: String?, at now: Date) -> [Signal] {
        front = FrontApp(bundleID: bundleID, host: host)
        if tracker.allowlist.isOnTask(bundleID: bundleID, host: host) { lastOnTaskBundleID = bundleID }
        return record(tracker.observe(bundleID: bundleID, host: host, at: now))
    }

    public mutating func tick(at now: Date) -> [Signal] {
        var signals = record(tracker.tick(at: now))
        if !completionSignalled && isComplete(totals(at: now), plannedMin: plannedMin) {
            completionSignalled = true
            signals.append(.reachedPlannedLength)
        }
        return signals
    }

    public mutating func setBreak(_ value: Bool, at now: Date) -> [Signal] {
        guard value != onBreak else { return [] }
        onBreak = value
        events.append(SessionEvent(value ? .breakStart : .breakEnd, at: now))
        return resuspend(at: now)
    }

    public mutating func setIdle(_ value: Bool, at now: Date) -> [Signal] {
        guard value != idle else { return [] }
        idle = value
        events.append(SessionEvent(value ? .idleStart : .idleEnd, at: now))
        return resuspend(at: now)
    }

    public mutating func setAsleep(_ value: Bool, at now: Date) -> [Signal] {
        guard value != asleep else { return [] }
        asleep = value
        events.append(SessionEvent(value ? .sleep : .wake, at: now))
        return resuspend(at: now)
    }

    /// "It's work: allow for this session" — allows whatever is in front now (spec 6.4).
    public mutating func allowCurrent(at now: Date) -> (entry: AllowEntry, signals: [Signal])? {
        guard let f = front else { return nil }
        let entry: AllowEntry
        if Browsers.supported.contains(f.bundleID.lowercased()), let host = f.host {
            entry = AllowEntry(.domain, host)
        } else {
            entry = AllowEntry(.app, f.bundleID)
        }
        allowAdded.append(entry)
        return (entry, record(tracker.allow(entry, at: now)))
    }

    public mutating func setExtraAllowed(_ ids: Set<String>, at now: Date) -> [Signal] {
        record(tracker.setExtraAllowed(ids, at: now))
    }

    public func totals(at now: Date) -> SessionTotals {
        sessionTotals(start: startedAt, end: now, events: events)
    }

    public func remainingSec(at now: Date) -> Int {
        max(0, plannedMin * 60 - totals(at: now).activeSec)
    }

    public mutating func finish(at now: Date, early: Bool, breakUsedEarlierTodaySec: Int, allowanceSec: Int) -> SessionResult {
        if tracker.isOffTask { events.append(SessionEvent(.offtaskEnd, at: now)) }
        if onBreak { events.append(SessionEvent(.breakEnd, at: now)) }
        if idle { events.append(SessionEvent(.idleEnd, at: now)) }
        if asleep { events.append(SessionEvent(.wake, at: now)) }
        let t = totals(at: now)
        let completed = !early && isComplete(t, plannedMin: plannedMin)
        let over = breakOverAllowance(usedEarlierSec: breakUsedEarlierTodaySec, sessionBreakSec: t.breakSec, allowanceSec: allowanceSec)
        return SessionResult(totals: t, completed: completed,
                             points: sessionPoints(totals: t, completed: completed, breakOverSec: over),
                             events: events, allowAdded: allowAdded)
    }

    private mutating func resuspend(at now: Date) -> [Signal] {
        record(tracker.setSuspended(onBreak || idle || asleep, at: now))
    }

    private mutating func record(_ outputs: [OffTaskTracker.Output]) -> [Signal] {
        var signals: [Signal] = []
        for o in outputs {
            switch o {
            case let .started(at, bundleID, host):
                events.append(SessionEvent(.offtaskStart, at: at))
                signals.append(.offTaskStarted(bundleID: bundleID, host: host))
            case let .ended(at):
                events.append(SessionEvent(.offtaskEnd, at: at))
                signals.append(.offTaskEnded)
            }
        }
        return signals
    }
}
```
